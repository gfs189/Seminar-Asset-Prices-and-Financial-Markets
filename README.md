## Data

Data is accessed via WRDS using the `tidyfinance` Python package. You will need valid WRDS credentials to download the raw data. Fama-French factors are downloaded from the Kenneth French data library and do not require credentials.

Raw data files are not tracked by git and must be generated by running the data download cells in `chapters/03_data_and_methodology.qmd` with `eval: true`.

## Rendering

```bash
# Render the full paper to PDF
quarto render index.qmd

# Preview with live reload (HTML)
quarto preview index.qmd

# Render the slides
quarto render "final slides/slides.qmd"
```
